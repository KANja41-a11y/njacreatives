## SEO files included

| File | Purpose |
|------|---------|
| `robots.txt` | Allows all crawlers + points to sitemap |
| `sitemap.xml` | Single-page sitemap for Google / Bing |
| `site.webmanifest` | PWA / installable web app metadata |
| `images/og-image.jpg` | Open Graph & Twitter card image (1200×630) |
| `images/favicon-*.png` + `favicon.ico` | Multi-size favicons + Apple touch icon |
| Meta tags in `index.html` | Description, OG, Twitter Card, canonical, theme-color, JSON-LD |

## Deploy

This repo is ready for GitHub Pages (branch `mainn` or your Pages source).

1. Push / re-deploy this version.
2. After live, submit sitemap & verify ownership (see the step-by-step guide).

## Quick SEO checklist after deploy

1. Google Search Console → add property `https://njacreatives.my.id/` → submit `sitemap.xml`
2. Bing Webmaster Tools → same
3. Test OG image: https://developers.facebook.com/tools/debug/ or https://cards-dev.twitter.com/validator
4. PageSpeed / Lighthouse check
5. Optional: Google Analytics / Search Console verification meta tag (add to `<head>` if needed)
