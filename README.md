# NJAcreative ✦ My Creative Journey

Website NJAcreative dengan favicon custom yang matching dengan branding pastel pink + lavender.

## Favicon
- `favicon.ico` — favicon utama browser
- `images/favicon.png` — versi PNG transparan
- `images/favicon-16.png` — ukuran 16×16
- `images/favicon-32.png` — ukuran 32×32
- `images/apple-touch-icon.png` — ikon perangkat 180×180

Favicon sudah dipasang di `index.html`, jadi tidak perlu menambahkan kode lagi.
